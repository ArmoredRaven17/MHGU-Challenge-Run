Rules

Setup

Pick any weapon class. Your first weapon must be root-tier from a Petrified, Iron, or Bone tree — whichever of those exist for that class (every class has Petrified; some lack Iron and/or Bone).

Weapon Lives

Start with 1 life. Gain +1 life every time Hunter Rank goes up from Hub content specifically — Village rank-ups don't count. A new life always starts at a tree's root, never partway up. Under Basic rules it can be any class; under Advanced rules it must stay your starting class. Chosen once when you start the run.

Failure

Failing a quest sells the weapon you failed with, permanently — no replacement. Gathered items are kept; zenny isn't tracked. The run ends when you'd have to sell your last remaining life.

Key Quests

Clear every Hub and Pub Key Quest — Village is left out of this checklist for now, since only Hub/Pub rank-ups grant a weapon life. Grouped here by rank tier; for now, a tier counts as done once every quest in it is checked off (the real trigger is a single "urgent" quest per tier, not yet distinguished in the data).

Restrictions

No Harvest Tours. No completing a quest via an optional subquest shortcut — clear the real main objective. No buying craftable items from the shop.

Victory

Chosen once at the start of a run, alongside Weapon Rules. Under Basic quest rules, slaying Ahtal-Ka is Victory. Under Advanced, Ahtal-Ka is a milestone — Victory also needs all three Fatalis, in the same run. Either way the run keeps going once Victory is reached.

Other MHGU Apps

Companion fan tools by the same author. Each opens in a new tab.

  • Quest Randomizer Rolls random quests when you can't decide what to hunt.
  • Collection Tracker Tracks which weapons, armor and Palico gear you own, and what it costs to finish them.
  • Equipment Box Mirrors the in-game box — 2000 hunter slots and 1000 Palico — so you can plan where things sit.
  • Bingo Builds a bingo card of hunting goals, with a shareable seed so a group can race the same board.
  • Hunting Log Keeps a running record of your hunts — what you were after, what you wore, who came along.
  • Zenny Gauntlet A scored challenge run — fail a hunt or get carted and you lose that weapon/style combo for the rest of the run.
  • Set Builder Assemble a full set by hand and see exactly which skills it activates.
  • Challenge Run you are here A permadeath challenge run — start from a root weapon, lose it on any quest failure, clear every Key Quest.
